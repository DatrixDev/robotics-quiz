Phần cần thuộc nhất
Computer Vision pipeline:

Image Acquisition
Thu nhận hình ảnh
↓
Data Preprocessing
Tiền xử lý dữ liệu
↓
Feature Extraction
Trích xuất đặc trưng
↓
High-Level Understanding
Hiểu ở mức cao

Object Detection → Bounding Boxes
Phát hiện vật thể → khung bao

Semantic Segmentation → Each Pixel
Phân đoạn ngữ nghĩa → từng pixel

Keypoint Detection → Points of Interest
Phát hiện điểm đặc trưng

Và nhóm model rất dễ ra:

YOLO → Single pass → Very fast → Real-time

Faster R-CNN → Two-stage → Slower → High accuracy

SSD → Single pass → Multiple feature maps

RetinaNet → One-stage → Focal loss → Class imbalance

CNN → Convolutional filters → Feature extraction

Generative Models → GANs, VAEs, Autoregressive, Flow-based.

Câu 50
Which statement best summarizes Autonomous Navigation?
Câu nào mô tả đúng nhất Autonomous Navigation?

A. A robot senses its environment, determines its location, plans a safe route, and controls its movement without human intervention.
Robot cảm nhận môi trường, xác định vị trí, lập tuyến đường an toàn và điều khiển chuyển động mà không cần con người can thiệp.

B. A robot only captures images and waits for a human to control every movement.
Robot chỉ chụp hình và chờ con người điều khiển mọi chuyển động.

C. A robot only detects objects but cannot move.
Robot chỉ phát hiện vật thể nhưng không thể di chuyển.

D. A robot moves randomly without sensing or planning.
Robot di chuyển ngẫu nhiên mà không cảm nhận hoặc lập kế hoạch.

Answer: A

Giải thích: Câu này tổng hợp các ý chính của slide:

Sensing → Localization → Planning → Control

Cảm nhận → Định vị → Lập kế hoạch → Điều khiển

và mục tiêu cuối cùng là robot có thể navigate and move independently without human intervention. 

🔥 Phần nên học thuộc trước khi thi
1. Autonomous Navigation

Navigate + Move Independently → Without Human Intervention
Tự điều hướng + tự di chuyển → không cần con người can thiệp.

2. Ba hoạt động cơ bản

Mapping → Navigating → Avoiding Obstacles
Lập bản đồ → Điều hướng → Tránh vật cản.

3. Bốn Core Components

Sensing → Localization → Planning → Control

Sensing: LiDAR + Camera + IMU → scan surroundings.
Localization: SLAM/GPS → exact position.
Planning: safe + efficient route → avoid obstacles.
Control: actuators + motors → execute motion. 
4. Sơ đồ Autonomous System

Physical World → Sense → Perceive → Plan → Act → Physical World

Sense → Collect data
Thu thập dữ liệu.

Perceive → Interpret data, track objects, build models, estimate state/localization
Hiểu dữ liệu, theo dõi vật thể, xây dựng mô hình, ước lượng trạng thái/vị trí.

Plan → Create a path to the goal
Tạo đường đến mục tiêu.

Act → Control vehicle to follow path
Điều khiển phương tiện đi theo đường.

Đặc biệt nếu thi trắc nghiệm, mình sẽ ưu tiên thuộc Sensing – Localization – Planning – Control và Sense – Perceive – Plan – Act, vì hai chuỗi này rất dễ bị đảo thứ tự để làm đáp án nhiễu.
